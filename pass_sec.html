Fortalecimiento de Acceso y Autenticación

Contraseñas

Contexto y objetivo

MAGINOT es un servidor multiusuario orientado a análisis bioinformáticos y administración de datos de investigación. En este contexto, el acceso a cuentas es un punto crítico de seguridad: una contraseña débil o compartida puede comprometer no solo la cuenta individual, sino también recursos, datos y servicios del sistema.

Por ello, se implementó una política mínima de contraseñas con dos principios:

  1. Responsabilidad individual: cada usuario es responsable de la seguridad de su contraseña.
-    No está permitido compartir contraseñas (ni con colegas, estudiantes o terceros).

-    Toda actividad realizada desde una cuenta se atribuye al titular de esa cuenta.
  1. Arranque seguro de cuentas nuevas: el administrador asigna una contraseña temporal inicial durante la creación de la cuenta.
-    En el **primer inicio de sesión**, la contraseña temporal debe cambiarse por una nueva, personal e intransferible.

-    El cambio inicial se acompaña de un mensaje con requisitos mínimos para evitar contraseñas triviales.

Requisitos mínimos de contraseña

  • Longitud mínima: 10 caracteres

  • Debe incluir al menos:

-    **1 minúscula**

-    **1 mayúscula**

-    **1 número**

-    **1 símbolo** (carácter especial)

Definir la política en /etc/security/pwquality.conf

Este archivo aplica y audita la política de complejidad a nivel sistema; lo utilizan passwd y pam_pwquality.so.

Editar el archivo:

sudo nano /etc/security/pwquality.conf

Ajustar (o asegurar) los siguientes parámetros:

# Longitud mínima de la contraseña
minlen  = 10

# Mínimo 1 letra minúscula
lcredit = -1

# Mínimo 1 letra mayúscula
ucredit = -1

# Mínimo 1 dígito
dcredit = -1

# Mínimo 1 símbolo
ocredit = -1

Verificación inmediata (para confirmar que ya aplica)

Para validar que la política se encuentra activa, se ejecutó:

passwd usuario

Se probó una contraseña que no cumpliera (por ejemplo, sin símbolo o con menos de 10 caracteres) y el sistema la rechazó. Posteriormente, se probó una contraseña que sí cumpliera, verificando que el cambio se completara correctamente.

Crear el script /usr/local/sbin/maginot-add-user

Con el fin de estandarizar el alta de cuentas, se creó un script administrativo para:

  • crear usuario y directorio home,

  • asignar una contraseña temporal robusta,

  • forzar cambio en el primer inicio de sesión,

  • (opcional) asignar grupos.

Crear el archivo:

sudo tee /usr/local/sbin/maginot-add-user >/dev/null <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
export LC_ALL=C

usage() {
  cat <<'USAGE'
Uso:
  sudo maginot-add-user [opciones] usuario

Opciones:
  -g  Grupos separados por coma (ej: mamba,docker)
  -s  Shell (default: /bin/bash)
  -c  Comentario/GECOS (nombre completo)
  -b  Directorio base para homes (default: /home) -> home será: BASE/usuario
  -d  Home directory explícito (sobrescribe -b), ej: /mnt/fury/home/usuario
  -l  Longitud de contraseña temporal (default: 18; mínimo efectivo 10)
USAGE
}

GROUPS=""
SHELL="/bin/bash"
COMMENT=""
HOME_BASE="/home"
HOME_DIR=""
PASS_LEN="18"

while getopts ":g:s:c:b:d:l:h" opt; do
  case "$opt" in
    g) GROUPS="$OPTARG" ;;
    s) SHELL="$OPTARG" ;;
    c) COMMENT="$OPTARG" ;;
    b) HOME_BASE="$OPTARG" ;;
    d) HOME_DIR="$OPTARG" ;;
    l) PASS_LEN="$OPTARG" ;;
    h) usage; exit 0 ;;
    \?) echo "Opción inválida: -$OPTARG" >&2; usage; exit 2 ;;
    :) echo "Falta argumento para -$OPTARG" >&2; usage; exit 2 ;;
  esac
done
shift $((OPTIND - 1))

USER="${1:-}"
if [[ -z "${USER}" ]]; then
  echo "Error: Debes indicar un usuario." >&2
  usage
  exit 2
fi

if [[ "$(id -u)" -ne 0 ]]; then
  echo "Error: Ejecuta como root (usa sudo)." >&2
  exit 1
fi

# Normaliza a minúsculas (recomendado)
USER="${USER,,}"

# Validación de username (minúsculas, números, _ o -)
if ! [[ "$USER" =~ ^[a-z_][a-z0-9_-]*$ ]]; then
  echo "Error: username inválido '$USER' (usa minúsculas, números, _ o -; no empieces con número)." >&2
  exit 2
fi

if id "$USER" &>/dev/null; then
  echo "Error: El usuario '$USER' ya existe." >&2
  exit 1
fi

# Home dir: si no se dio -d, se construye con -b
if [[ -z "$HOME_DIR" ]]; then
  HOME_DIR="${HOME_BASE%/}/$USER"
fi

# Asegura que el directorio padre exista
BASE_DIR="$(dirname "$HOME_DIR")"
if [[ ! -d "$BASE_DIR" ]]; then
  mkdir -p "$BASE_DIR"
  chmod 755 "$BASE_DIR"
fi

# --- Generador de contraseña temporal (sin pipes) ---
# Símbolos permitidos (evitamos ':' y espacios)
SYMBOLS='@#%+=_!^*?-'

if command -v python3 >/dev/null 2>&1; then
  PASS="$(PASS_LEN="$PASS_LEN" SYMBOLS="$SYMBOLS" python3 - <<'PY'
import os, secrets, string
length = int(os.environ.get("PASS_LEN", "18"))
symbols = os.environ.get("SYMBOLS", "@#%+=_!^*?-")
alphabet = string.ascii_letters + string.digits + symbols

while True:
    pw = ''.join(secrets.choice(alphabet) for _ in range(length))
    if len(pw) >= 10 \
       and any(c.islower() for c in pw) \
       and any(c.isupper() for c in pw) \
       and any(c.isdigit() for c in pw) \
       and any(c in symbols for c in pw):
        print(pw)
        break
PY
)"
else
  echo "Error: python3 no está disponible (instálalo o ajusta el generador)." >&2
  exit 1
fi

# --- Crear usuario (con home en ruta personalizada) ---
if [[ -n "$COMMENT" ]]; then
  useradd -m -d "$HOME_DIR" -k /etc/skel -s "$SHELL" -c "$COMMENT" "$USER"
else
  useradd -m -d "$HOME_DIR" -k /etc/skel -s "$SHELL" "$USER"
fi

# Por si acaso: si no se creó home, créalo
if [[ ! -d "$HOME_DIR" ]]; then
  mkdir -p "$HOME_DIR"
  chown "$USER:$USER" "$HOME_DIR"
  chmod 700 "$HOME_DIR"
fi

# Asignar contraseña temporal
echo "${USER}:${PASS}" | chpasswd

# Forzar cambio en primer login
chage -d 0 "$USER"

# Agregar a grupos (opcional)
if [[ -n "$GROUPS" ]]; then
  usermod -aG "${GROUPS//,/ }" "$USER"
fi

echo "Usuario creado: $USER"
echo "Home: $HOME_DIR"
echo "Contraseña temporal: $PASS"
echo "Acción: Se forzó cambio de contraseña al primer login (chage -d 0)."
EOF

Asignar permisos correctos:

sudo tee /usr/bin/maginot-add-user >/dev/null <<'EOF'
#!/usr/bin/env bash
exec /usr/local/sbin/maginot-add-user "$@"
EOF

sudo chmod 750 /usr/local/sbin/maginot-add-user
sudo chown root:root /usr/local/sbin/maginot-add-user

Nota de seguridad: el script imprime la contraseña temporal en pantalla. Se recomienda compartirla una sola vez y por un canal seguro.

Uso del script (alta de usuarios)

Ejemplo simple:

sudo maginot-add-user usuario_nuevo

Con grupos:

sudo maginot-add-user -g mamba,docker usuario_nuevo

Con nombre completo:

sudo maginot-add-user -c "Juan Pérez" usuario_nuevo

Cómo crear el home en otra ruta:

sudo maginot-add-user -b /srv/fury/home usuario1

Mensajes de política (una sola vez)

Mensaje antes del login SSH (opcional): /etc/issue.net + Banner

sudo tee /etc/issue.net >/dev/null <<'EOF'
Servidor MAGINOT - Aviso de seguridad
No compartas tu password.
EOF

Activa Banner en SSH:

sudo grep -n '^Banner' /etc/ssh/sshd_config || true

Si no aparece, agrega:

echo 'Banner /etc/issue.net' | sudo tee -a /etc/ssh/sshd_config
sudo systemctl restart sshd

Configuración de SSH

Contexto y objetivo

SSH es el punto de entrada principal para administración remota. Para reducir la superficie de ataque y mitigar intentos de fuerza bruta, se endureció la configuración del demonio sshd con medidas básicas: deshabilitar acceso directo de root, mover el puerto por defecto, limitar intentos de autenticación, prohibir contraseñas vacías y reducir el tiempo permitido para completar el inicio de sesión.

Cambios en /etc/ssh/sshd_config

Respaldar el archivo:

sudo cp -a /etc/ssh/sshd_config /etc/ssh/sshd_config.bak.$(date +%F_%H%M)

Editar configuración:

sudo nano /etc/ssh/sshd_config

Asegurar estas directivas (pueden colocarse al final para que prevalezcan):

# --- MAGINOT: Hardening SSH ---

# Cambiar puerto (ejemplo: 14420)
Port 14420

# No permitir login directo de root
PermitRootLogin no

# No permitir contraseñas vacías
PermitEmptyPasswords no

# Limitar intentos de autenticación por conexión
MaxAuthTries 6

# Reducir el tiempo para completar el login 
LoginGraceTime 2m

Validar sintaxis y recargar:

sudo sshd -t
sudo systemctl reload sshd

Activar Fail2Ban

Instalar:

sudo dnf install -y fail2ban

Habilitar y arrancar:

sudo systemctl enable --now fail2ban
sudo systemctl status fail2ban --no-pager -l

Crear un archivo dedicado:

sudo tee /etc/fail2ban/jail.d/sshd.local >/dev/null <<'EOF'
[sshd]
enabled = true

# Tu puerto SSH (ajústalo si usas otro)
port = 14420

# En Rocky, lo más robusto suele ser leer del journal
backend = systemd

# Política: 3 intentos en 10 minutos => ban 1 hora
maxretry = 3
findtime = 10m
bantime  = 1h

# No te bloquees a ti mismo (agrega aquí tu(s) IP(s) de confianza)
ignoreip = 127.0.0.1/8 ::1 132.248.13.8/32

# Acción usando firewalld (recomendado en Rocky)
banaction = firewallcmd-ipset
EOF

Recargar y verificar:

sudo fail2ban-client reload
sudo fail2ban-client status
sudo fail2ban-client status sshd

Revisar eventos:

sudo journalctl -u sshd -n 200 --no-pager
sudo tail -n 200 /var/log/fail2ban.log

Desbanear una IP (si aplica):

sudo fail2ban-client set sshd unbanip X.X.X.X
